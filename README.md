# my-kart

我的第一个 3D 网页项目。用它学会「从零到发布 GitHub」的完整流程。

> 这个名字是占位，随便改。改名成本：改文件夹名 + 改这一行，1 分钟。

## 现在能干什么

浏览器里显示一个缓慢旋转的蓝色立方体。

## 怎么跑

**不能直接双击 `index.html`。** 因为 `main.js` 用了 `import` 语法（`type="module"`），
浏览器对"本地文件之间互相 import"有安全限制。

必须通过一个本地服务器打开。在 Git Bash 里：

```bash
cd D:/tianshu/task/webgame/my-kart
python -m http.server 8000
```

然后浏览器打开 http://127.0.0.1:8000

关掉服务器：回到终端按 `Ctrl + C`。

## 怎么验证它是对的

| 检查项 | 怎么算通过 |
|---|---|
| 画面渲染出来了 | 看到一个蓝色方块，不是黑屏也不是报错 |
| 方块在转 | 盯着看 3 秒，它在缓慢旋转 |
| 缩放不变形 | 拖动浏览器窗口大小，方块保持正方体，不被拉长压扁 |

## 文件说明

| 路径 | 作用 |
|---|---|
| `index.html` | 网页骨架，把画布放上去 |
| `src/main.js` | 3D 逻辑：场景、相机、方块、动画循环 |
| `vendor/three/` | Three.js 库本体（本地副本，断网也能跑） |
| `PROGRESS.md` | 进度记录。**每次换窗口前更新它** |
| `.rivet.md` | 告诉 AI 这个项目用什么技术、有什么约定 |

## 为什么不用 npm / Vite

现在刻意不装任何构建工具——**先用最原始的方式跑通，你才能体会后面为什么要引入工具**。
等这个项目长到几十个文件、加载慢得难受的时候，我们再把 Vite 加进来，那时你会立刻明白它解决什么问题。
